# Homebrew Tap for Clack

Install the current Clack alpha with Homebrew:

```sh
brew install --cask In-sp3ctr3/tap/clack
```

Or tap the repository first:

```sh
brew tap In-sp3ctr3/tap
brew install --cask clack
```

Clack alpha builds are unsigned and not notarized yet, so macOS may warn before opening the app.

Project source and releases live at [In-sp3ctr3/clack](https://github.com/In-sp3ctr3/clack).
